# Spin vs Kramers-Restricted MP2 Notes

This repository contains LaTeX notes on the relationship between spin-restricted / spin-unrestricted MP2 and Kramers-restricted relativistic MP2, compiled into a PDF using GitHub Actions.

## Contents

- `main.tex` – Main LaTeX source for the notes (book class, single chapter at present).
- `.github/workflows/latex.yml` – Continuous integration workflow that builds the PDF on each push to `main` and commits the updated PDF back to the repository.[web:19][web:23][web:25]
- `main.pdf` – Autogenerated PDF output (not tracked manually; updated by the workflow).

## LaTeX document

The document is written in `book` class with 11pt oneside layout and uses standard mathematical packages:

- `amsmath`, `amssymb`, `amsthm`, `mathtools` for equations and theorem-like environments.[web:26][web:28]
- `geometry` for 1 inch margins.
- `hyperref` and `cleveref` for cross-references and hyperlinks.
- `enumitem` for flexible lists.

The current content focuses on:

- Spin-unrestricted non-relativistic MP2 energy and its spin decomposition.
- Spin-restricted MP2 energy obtained by dropping explicit spin indices.
- Kramers-unrestricted relativistic MP2 with time-reversal symmetry relations between electron repulsion integrals.

You can compile locally with any reasonably complete TeX Live installation, for example via:

```bash
latexmk -pdf main.tex
